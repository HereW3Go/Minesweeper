## Thought process - Planning Gameplay Loop & Logic
### My Articulated Idea
- Open game to the MainMenu screen, which has the button Start Game, which takes them to the game, where a timer starts counting up from 0, timing the user.
- Player left clicks anywhere on map (30 width x 20 height).
- The clicked cell should not be a bomb, so they dont fail. When they click, bombs are scattered randomly around the map, just ensuring the initially clicked cell isnt a mine.
- Algorithm goes round to empty all cells to show blank where there's no mines.
- When the algorithm reaches a cell where there's a bomb within a 1 cell radius on all sides (diagonally, horizontally & vertically) of it, it gives that cell a number to dictate how many mines that cell is touching.
- User can right click a cell to plant a flag on that cell, preventing the user from being able to click that cell, allowing the user to safely mark squares that they deem unsafe & keep track of them.
- If a user left clicks a safe cell, same checks happen to clear out more spaces.
- If the user clicks a mine though, all mines are displayed on the map, & game ends, with option to replay, or go back to MainMenu.
